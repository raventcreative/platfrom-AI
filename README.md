# ProdPilot — AI Agent Production Automation Platform

Platform di mana **AI agent menjalankan otomasi produksi konten end-to-end** berdasarkan satu prompt tingkat tinggi.

Contoh: _"Buatkan produk kecantikan serum Vitamin C. Buatkan skrip iklan 30 detik dan video dari skrip itu."_ → platform menghasilkan **brief → skrip → storyboard → video + voice-over → aset siap publikasi**, dengan kontrol review tim produksi di setiap tahap.
